# Geminga — канал обновлений

Здесь лежат только установщики [Geminga](https://github.com/timka-robin/macstudiorank)
и контрольные суммы к ним. Исходный код, история разработки и рабочие данные
пользователей в этом репозитории не публикуются.

## Что скачать

Откройте последний релиз и возьмите файл под свою систему:

| Система | Файл |
| --- | --- |
| macOS, Apple Silicon (M1 и новее) | `Geminga_<версия>_aarch64.dmg` |
| macOS, Intel | `Geminga_<версия>_x64.dmg` |
| Windows | `Geminga_<версия>_x64-setup.exe` или `..._x64_en-US.msi` |

Рядом с установщиками лежит `SHA256SUMS.txt` — контрольные суммы SHA-256. Их можно
сверить перед установкой:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Сборки не подписаны сертификатом разработчика, поэтому macOS и Windows показывают
предупреждение при первом запуске. Подпись появится позже.

## Обновления

Приложение само проверяет последний опубликованный релиз в этом репозитории и
показывает версию, список изменений и ссылку на подходящий установщик. Установку
пользователь выполняет сам: тихой подмены приложения нет. Предрелизы с суффиксом
в версии приложение не видит.

## Чего здесь нет

- исходного кода и истории разработки;
- ключей, токенов и настроек CI;
- баз данных, журналов и любых данных пользователей.
